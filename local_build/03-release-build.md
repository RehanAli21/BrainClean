# 03 — Release Build (signed)

For Play Store uploads (AAB) or distributing signed APKs to users.

## Step 1 — Choose your keystore path

### A) Reuse your existing EAS keystore (REQUIRED if you've already uploaded to Play Store)

Play Store remembers which key signed your first upload. If you switch to a different key, Play rejects every future upload from your account. So if you have ANY build live on Play Console (even Internal Testing), use the EAS keystore.

Download it from EAS:

```powershell
npx eas credentials
```

Then in the interactive menu:
1. Select **Android**
2. Select **production** profile
3. Select **Keystore: Manage everything needed to build your project**
4. Select **Download credentials from Expo to credentials.json**

This creates two files at the project root:
- `credentials.json` — references the keystore file + passwords
- A `.jks` or `.p12` keystore file (path is in `credentials.json`)

**Open `credentials.json`** to see the keystore filename, alias, and passwords. Copy those into Step 3 below.

### B) Generate a fresh keystore (ONLY if you've never published to Play Store)

```powershell
keytool -genkeypair -v -storetype PKCS12 `
  -keystore brainclean-release.keystore `
  -alias brainclean `
  -keyalg RSA -keysize 2048 -validity 10000
```

Answer the prompts (name, org, city, country). Set a strong password — write it down. **If you lose this keystore or password, you can never update your app on Play Store.**

Note your values:
- File: `brainclean-release.keystore`
- Alias: `brainclean`
- Store password: (what you typed)
- Key password: (usually same as store password)

## Step 2 — Place the keystore

Move the `.keystore` (or `.jks` / `.p12`) file to:

```
D:\rehan\GrayGuard\android\app\<your-keystore-file>
```

## Step 3 — Configure Gradle to find it

Create or edit `android\gradle.properties` and add these four lines (the names must match exactly — `withProductionAndroidConfig.js` reads them):

```properties
BRAINCLEAN_UPLOAD_STORE_FILE=brainclean-release.keystore
BRAINCLEAN_UPLOAD_KEY_ALIAS=brainclean
BRAINCLEAN_UPLOAD_STORE_PASSWORD=your-store-password-here
BRAINCLEAN_UPLOAD_KEY_PASSWORD=your-key-password-here
```

The store file path is **relative to `android/app/`**, so just the filename if you placed it there.

> SECURITY: `android/` is regenerated by prebuild and is in `.gitignore` (or should be). Never commit `gradle.properties` containing real passwords. For a more permanent setup, put these lines in your global `C:\Users\rehan\.gradle\gradle.properties` instead — that file survives every `prebuild --clean`.

## Step 4 — Set production env var

```powershell
$env:EXPO_PUBLIC_API_BASE_URL = "https://api.brainclean.app/api"
```

## Step 5 — Bump version

Edit `app.json`:

```json
"version": "1.0.1"          // user-visible version
```

And in `android/app/build.gradle` (regenerated by prebuild, so set it in `app.json` instead via `versionCode` — or bump manually after prebuild):

```
versionCode 4               // must be higher than your last Play Store upload (which was 3)
```

The cleaner path: add `"versionCode"` under `"android"` in `app.json`:

```json
"android": {
    "versionCode": 4,
    ...
}
```

Then prebuild will set it for you.

## Step 6 — Prebuild + build

```powershell
cd D:\rehan\GrayGuard
npx expo prebuild --platform android --clean
cd android
.\gradlew.bat bundleRelease       # for Play Store (.aab)
# OR
.\gradlew.bat assembleRelease     # for sideloading (.apk)
```

## Step 7 — Find your artifact

```
AAB → D:\rehan\GrayGuard\android\app\build\outputs\bundle\release\app-release.aab
APK → D:\rehan\GrayGuard\android\app\build\outputs\apk\release\app-release.apk
```

## Step 8 — Verify it's signed correctly

```powershell
# Should print "Verifies" and show your cert
.\gradlew.bat signingReport
```

Or check the APK directly:

```powershell
# Find your build-tools path, e.g. C:\Users\rehan\AppData\Local\Android\Sdk\build-tools\35.0.0\
& "$env:ANDROID_HOME\build-tools\35.0.0\apksigner.bat" verify --print-certs app\build\outputs\apk\release\app-release.apk
```

If using the EAS keystore, the SHA1 fingerprint here MUST match what Play Console shows under **Setup → App integrity → App signing**.

## Step 9 — Upload to Play Store

1. Go to https://play.google.com/console
2. Pick the BrainClean app → **Production** (or Internal Testing) → **Create new release**
3. Upload the `.aab` file
4. Fill in release notes, save, review, roll out

---

## Subsequent release builds

After the initial setup, releases take three commands:

```powershell
# bump versionCode in app.json first
$env:EXPO_PUBLIC_API_BASE_URL = "https://api.brainclean.app/api"
npx expo prebuild --platform android --clean
cd android; .\gradlew.bat bundleRelease
```

Total time: ~3–8 minutes once Gradle caches are warm.
