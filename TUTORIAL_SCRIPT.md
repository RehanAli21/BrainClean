# BrainClean — App Tutorial Script

Hello, I created this application to block apps from distracting me.

To use this application, you first have to create account using this signup page.

Then login using your account.

The first screen will be tasks screen, where you can see, and create tasks.

But before creating task we have to do some setup, first go to settings and give permissions.

First one is blocking notification, because it distract me.

Then I am going to give all these permissions. These permission are necessary because application have to see what application you are opening and block you from using them.

After permissions lets select the apps, that I have to block. As you can see I already have apps select because I am already using this brainclean.

Now lets create task, the description is focus work, you can put anything in this, and the duration is 30 minutes which is half hour.

The task is created and now we can start it. Now that blocking started, we can see the apps which we marked to block.

As you can see when you try to open blocked app, it shows this overlay that it is blocked.

Now after 30 minutes you can finish task and blocking will be stopped. One more thing if you do not finish task the blocking automatically stops after the maximum time, which can be adjusted in settings. The default max time is 600 minutes which are 10 hours.
